Flagship product

Smart Queue for hospitals and clinics.

Waiting rooms waste the morning. Reception, the doctor, and the patient should see the same live token and the same wait time. Paper tokens and shouted names are the old system. This replaces them.

  • Reception, doctor, and patient views stay in sync.
  • Live token number and a simple estimated wait.
  • Works in the browser. No app install for patients.
  • Built for a small clinic first — not a 500-bed brochure.

Who built this

A company page, so you know who answers the phone.

If you are considering Smart Queue, you will ask who is behind it. This site exists for that question.

JMR Apps is run by an operator who still manages a cable television network of about 2,000 customers. The billing, collections, box stock, and field-collector tools used on that network were written here — and are used every day, including by two other operators.

That is the working method: see the friction at the counter, build the smallest system that removes it, then keep it running. Smart Queue comes from the same method, applied to a clinic waiting room.

What we will not claim

This is not a venture studio with ten commercial products. Other tools on this site were built to learn, or to solve a personal need. They are listed so the work is visible. They are not the business we are asking you to buy.

If you run a clinic or a cable network and the current system wastes the morning, write to the person who built the software.
